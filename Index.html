Rekap Pembayaran Piutang Toko

Cara import pembayaran:

  1. Klik Download Template untuk mendapatkan file Excel contoh.
  2. Isi kolom sesuai panduan: Tgl Bayar (dd/mm/yyyy, wajib), No Anggota (wajib), Jumlah Bayar (angka > 0, wajib), Nota/Keterangan & Metode (opsional). Pembayaran diakumulasikan otomatis berdasarkan No Anggota (tidak perlu input ID Piutang).
  3. Pilih file (format .xlsx / .xls), lalu klik UPLOAD PEMBAYARAN.
  4. Pembayaran masuk ke sheet PembayaranPiutang, mengurangi sisa tagihan otomatis berdasarkan total piutang anggota, dan limit kredit bulan ini ikut diperbarui.

Baris duplikat (No Anggota + Jumlah + Tanggal sama) otomatis dilewati; baris yang tidak valid dilaporkan dan tidak disimpan.
